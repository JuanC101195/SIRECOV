Acerca del B+ Tree

El Árbol B+ es una estructura de datos optimizada para búsquedas por rango. En SIRECOV, lo usamos para indexar fechas y realizar consultas eficientes.

Características:

  • ✅ Búsqueda: O(log n)
  • ✅ Inserción: O(log n)
  • ✅ Búsqueda por rango: O(log n + k)
  • ✅ Auto-balanceo garantizado
  • ✅ Todas las hojas al mismo nivel
  • ✅ Hojas enlazadas para recorridos secuenciales

Ventajas en SIRECOV:

  • 🚀 Consultas por rango de fechas ultra-rápidas
  • 📊 Perfecto para generar estadísticas temporales
  • 💾 Uso eficiente de memoria (50-100% ocupación)
  • 📈 Escalable a grandes volúmenes de datos

Complejidad del Grado (t=3):

Cada nodo puede tener:

  • Mínimo: 2 claves (t-1)
  • Máximo: 5 claves (2t-1)
