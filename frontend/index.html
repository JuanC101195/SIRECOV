📚 Comparación de Algoritmos

⚡ Búsqueda Hash:

• Complejidad: O(1) promedio

• Usa índices preconstruidos

• Ultra-rápida para búsquedas exactas

🐌 Escaneo Lineal:

• Complejidad: O(n)

• Recorre todos los registros

• Más lento pero universal
